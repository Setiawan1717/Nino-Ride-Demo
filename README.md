# Nino Ride (Demo)

Contoh desain website untuk Bengkel Mobil Nino Ride, Tlogomas, Malang. **Bukan website resmi.**

- Satu file: `index.html` (HTML, CSS, dan JS jadi satu).
- Data yang mudah diedit ada di bagian atas script: `DATA` (nomor WA, jam, layanan, keluhan) dan `FOTO` (foto contoh dari Unsplash, ganti dengan foto asli bengkel).
- `demo: true` membuat tombol WhatsApp hanya menampilkan contoh pesan. Ganti ke `false` setelah pemilik setuju.
- Perlu konfirmasi pemilik: jam bengkel, rating Google, area home service.
